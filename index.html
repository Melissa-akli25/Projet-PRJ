MIAGE Connect

La plateforme collaborative d'entraide interuniversitaire : trouver des pairs partageant les mêmes matières, localiser un espace de travail, suivre les blocages de campus et organiser ses révisions.

Dossier de projet (PDF) Code source Versions

Le projet

Face aux difficultés pédagogiques, aux blocages de campus et à l'isolement, les étudiants peinent à trouver rapidement de l'aide ciblée et des lieux adaptés pour travailler. MIAGE Connect met en relation des étudiants de différentes universités et calcule des décisions utiles : identifier les matières équivalentes, former des groupes équilibrés, évaluer la gravité des blocages signalés, recommander des ressources et planifier les révisions.

Architecture

Front web (React) → API REST (Spring Web, documentée avec OpenAPI / Swagger) → back Java / Spring Boot avec couche algorithmique découplée → MySQL via Spring Data JPA / Hibernate. Tests unitaires et d'intégration (JUnit 5), conteneurisation Docker et intégration continue via GitHub Actions.
